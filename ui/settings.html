Summaries & Agents

When focus ends, an expandable card lists what was held — hover to see each update with its time. Off: you get the one-line summary glow only.

Unlocking after 30+ minutes shows a digest of what arrived while the screen was locked.

Agent completions (the glow-agent cue) breathe in the bottom-right corner until you are back at the keyboard, then replay their message once. Off: they render as a normal one-shot glow.

An agent blocked on your approval wastes time every second it waits, so its beacon (bottom-left, glow-blocked) grows brighter and more insistent with age — never a comet, never a sound. Being back at the keyboard does not clear it; only answering the agent, or dismissing it from the tray, does. Off: it renders as a normal completion beacon.

On by default: a blocked agent is your own delegated work asking for the one thing only you can give. Off: it is held like any other ambient cue and appears in the constellation.

Windows

While Windows is set to Do Not Disturb, presenting, or you toggle Focus mode from the tray, only urgent cues get through. Everything else is held and summarized in a single quiet glow when focus ends.

Polls your Teams presence through Microsoft Graph: in a call, presenting, or Do Not Disturb (including Focusing) holds ambient cues like focus mode does. Uses the Graph token above, which then also needs the Presence.Read scope.

Application

Updates download quietly in the background, announce themselves as a single ambient glow, and install when you quit. Never a popup.

A failing poller (expired token, rate limit) puts an amber dot on the tray icon and its reason in the tooltip, instead of failing silently.

Start-at-login and auto-update apply to the installed build only; this is a development run.
